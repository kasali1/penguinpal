# Project 3 - *CATNI (CHANI for Cats)*

Submitted by: **[annah kasali]**

**CATNI** is an Android app that replicates the layout and design of the **CHANI** astrology app, created for cats! It includes a welcome splash screen, log in and sign up forms, and a daily cat horoscope dashboard.

Time spent: **3** hours spent in total

## User Stories

The following **required** functionality is completed:

* [x] **Pick an app screenshot to duplicate** (CHANI Astrology App)
* [x] **Create a runnable app that displays an Animal Version of your chosen screenshot**
* [x] **Layout uses 1 or more ConstraintLayout**
* [x] **Layout uses 1 or more ImageView**
* [x] **Layout uses 3 or more TextViews**

The following **stretch** features are implemented:

* [x] **Interactive Log In & Sign Up screens with `EditText` input fields**
* [x] **Personalized Daily Cat Horoscope Dashboard (`HomeActivity`)**
